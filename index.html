Privacy Policy for Budget Manager

Effective date: August 6, 2026
Last updated: August 6, 2026

Budget Manager is an offline-first budgeting application. It does not require an account, login, or connection to a Budget Manager cloud service. Financial records are primarily stored locally on the user's device.

1. Information handled by the application

Budget Manager allows users to enter and manage information such as:

  • Account names and currencies;
  • Income, expenses, budgets, categories, and recurring payments;
  • Merchant names, notes, tags, and receipt images;
  • Financial goals, sinking funds, debts, and installments;
  • Imported CSV or OFX bank-statement information;
  • Manual exchange rates and categorization rules.

This information is entered voluntarily and is stored locally on the device. The developer does not operate a backend that receives or stores these financial records.

2. Camera, images, and receipt recognition

Budget Manager requests camera access only when the user chooses to scan or attach a receipt. Users can deny camera access and enter transaction information manually.

Receipt images and extracted receipt information are processed on the device and stored with the user's local application data. Budget Manager uses Google ML Kit for text recognition. Google states that ML Kit input images and recognition results are processed on-device and are not sent to Google servers.

3. Files, imports, exports, and backups

Budget Manager uses the operating system's file picker when the user chooses to import a statement, restore a backup, or export data. The app does not scan unrelated files.

CSV and OFX statements are parsed locally. Backup and export files are created only when requested by the user and are saved to a location chosen by the user.

Exported files may contain sensitive financial information. Users are responsible for protecting, encrypting, sharing, and deleting those files.

4. Third-party software and diagnostic information

Budget Manager uses Google ML Kit for on-device receipt text recognition. According to Google's ML Kit disclosure documentation, the SDK may collect limited device information, application information, performance metrics, and per-installation identifiers for diagnostics and usage analytics. Google states that this information is encrypted in transit and is not shared with third parties.

ML Kit may contact Google servers to obtain updates, compatibility information, bug fixes, or machine-learning model information. Receipt images and recognized receipt text are not sent to Google for recognition.

Current versions of Budget Manager may use Google Fonts to retrieve and cache font resources. Such requests may expose standard network information, including the device's IP address, to Google's font infrastructure.

Budget Manager does not currently include advertising SDKs, behavioral advertising, developer-operated analytics, or a developer-operated cloud synchronization service.

5. Data sharing and sale

The developer does not sell users' financial information or receipt content. The developer does not receive users' locally stored budgets, transactions, imported statements, or backup files.

Information handled by third-party SDKs is subject to the providers' applicable terms and privacy practices.

6. Data retention and deletion

Application data remains on the device until the user deletes individual records or accounts, clears the application's storage, or uninstalls the application.

Because Budget Manager does not maintain user accounts or a cloud database, there is no server-side account to delete. Backup and export files must be deleted separately from the locations where the user saved them.

7. Security

Budget Manager uses Android application storage protections. However, no storage or transmission method can be guaranteed to be completely secure. Users should protect their devices with an appropriate screen lock and keep backup files in a secure location.

8. Children's privacy

Budget Manager is intended as a general financial planning tool and is not designed for children. The developer does not knowingly collect personal information from children through a Budget Manager account or backend.

9. Financial disclaimer

Budgets, forecasts, automatic categories, subscription detection, and other insights are planning aids. They do not constitute financial, accounting, tax, investment, or legal advice.

10. Changes to this policy

This policy may be updated when the application's functionality, third-party SDKs, or legal requirements change. The effective date and last-updated date at the top of this page will identify the latest version.
